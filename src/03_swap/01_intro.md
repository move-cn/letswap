# 固定汇率交换

在理解 Swap 的核心原理之前，我们先从最简单的模型入手：固定汇率交换。这一章会实现一个固定汇率的 USD/RMB 兑换合约，帮助大家理解 Swap 的基本流程。

## 什么是固定汇率

固定汇率是指两种货币之间的兑换比例是预先设定好的、不会随市场供需变化的汇率。

以 USD 和 RMB 为例，假设固定汇率为：

- **1 USD = 7.3 RMB**

那么：

- 你拿 1 USD，固定换到 7.3 RMB
- 你拿 1 RMB，固定换到 1 / 7.3 = 0.137 USD（约 0.14 USD）

## 汇率计算：整数运算的技巧

在智能合约中，我们通常用最小单位来表示币的数量（类似"分"和"元"的关系）。为了避免浮点数精度问题，汇率计算全部使用整数乘除法。

以汇率为例，将 7.3 放大 10000 倍来表示：

- **1 USD = 7.3 RMB** 对应 **10000 : 73000**

由此推导出两个方向的兑换公式：

**USD 换 RMB：**

```
amt_rmb = amt * 73000 / 10000
```

例如存入 1 USD（amt = 1），得到 1 * 73000 / 10000 = 7 RMB。

**RMB 换 USD：**

```
amt_usd = amt * 10000 / 73000
```

例如存入 7.3 RMB（amt = 7.3），得到 7.3 * 10000 / 73000 = 1 USD。

> 注意：Move 语言中整数除法是向下取整，所以实际计算中可能存在微小的精度损失，这在 DeFi 中是需要考虑的因素。

## 币对与储备：Bank 结构体

要在两种货币之间进行自动兑换，合约必须持有这两种货币的储备。就好比现实中的外汇兑换窗口，你想用 RMB 换 USD，窗口必须先有 USD 的库存才能完成兑换。

在代码中，我们用一个 `Bank` 结构体来存储这对货币的储备：

```
public struct Bank has key {
    id: UID,
    rmb: Balance<RMB>,
    usd: Balance<USD>,
}
```

- `Bank` 是一个共享对象（shared object），任何用户都可以访问它来进行兑换
- `rmb` 字段存储合约持有的 RMB 余额
- `usd` 字段存储合约持有的 USD 余额

这样一对互相兑换的货币组合，我们称之为**币对（Coin Pair）**。本章的例子中，币对就是 USD/RMB。

## 交换流程概览

整个 Swap 合约的流程分为三个阶段：

**1. 存入储备（deposit）**

管理员或流动性提供者向 Bank 中存入 USD 和 RMB，为后续兑换提供库存。

**2. 执行交换（swap）**

用户拿一种币存入 Bank，合约按固定汇率计算出另一种币的数量，从 Bank 的储备中转出给用户。

以 RMB 换 USD 为例：
- 用户存入 RMB 到 Bank
- 合约计算 `amt_usd = amt * 10000 / 73000`
- 合约从 Bank 的 USD 储备中取出对应数量，转给用户

**3. 提取储备（withdraw）**

管理员可以通过 `AdminCap` 权限从 Bank 中提取储备的币。

```
deposit --> swap --> withdraw
  |          |         |
  v          v         v
提供储备   用户兑换    管理提取
```

## 本章小结

本章介绍了固定汇率交换的核心概念：

- 固定汇率的兑换比例是预设的，不随市场变化
- 整数运算使用放大倍数（如 73000/10000）避免浮点数精度问题
- Bank 结构体作为共享对象存储币对储备
- Swap 流程分为三个阶段：存入储备 → 执行交换 → 提取储备
