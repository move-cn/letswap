# Swap 经济模型

Swap 的核心是一个资金池,池子里存放着两种代币,供用户随时兑换。但资金不会凭空出现在池子里,必须有人愿意把自己的代币存进去。在 DeFi 中,我们把这些人叫做**流动性提供者 (Liquidity Provider, 简称 LP)**。

LP 把自己的代币存入资金池,本质上就是在给 Swap "当银行"。既然是银行,就必须回答一个根本问题:LP 把钱存进来,能得到什么好处?

# 手续费: LP 收益的来源

每一笔 Swap 交易,兑换者都需要支付一笔手续费。以 Uniswap V2 为例,每笔交易收取 **0.3%** 的手续费。

举个例子:

- 用户用 100 USDT 兑换 SUI
- 手续费为 100 * 0.3% = 0.3 USDT
- 这 0.3 USDT 不会给到任何中心化机构,而是直接留在资金池里,归所有 LP 共同所有

因为 Swap 合约全天候运行,交易笔数越多,累积的手续费就越多,LP 的收益也就越高。这就是 LP 提供流动性的动力:不需要自己交易,只要别人来换,就能被动赚取手续费。

# LP Token: 你在池子里的份额凭证

当 LP 向资金池存入代币时,合约会铸造 **LP Token** 给 LP,作为其持有池子份额的凭证。

LP Token 的作用:

- **代表份额**: 你持有的 LP Token 占总发行量的比例,就是你在池子中的资产占比
- **提取资产**: 凭 LP Token 可以赎回池子中对应比例的两种代币
- **累积收益**: 随着手续费不断注入池子,池子里的资产总量会增长,但 LP Token 的数量不变,所以每个 LP Token 对应的资产价值会不断增加

举个例子:

- 池子里有 10000 USDT + 10000 SUI,LP Token 总量为 1000 个
- 你持有 100 个 LP Token,占比 10%
- 你可以赎回 1000 USDT + 1000 SUI
- 经过一段时间,手续费累积使池子增长到 10500 USDT + 10500 SUI
- 你的 100 个 LP Token 现在对应 1050 USDT + 1050 SUI

# 无常损失

提供流动性并非没有风险。LP 需要同时存入两种代币,当两种代币的价格发生相对变化时,LP 的资产组合会和单纯持有代币产生差异,这种差异叫做**无常损失 (Impermanent Loss)**。

简单理解:

- 你存入了等值的 USDT 和 SUI
- 如果 SUI 价格大幅上涨,套利者会不断用 USDT 换走 SUI,导致你持有的 SUI 变少、USDT 变多
- 相比于当初什么都不做、直接持有 SUI,你的资产价值会更低
- 这部分差额就是无常损失

之所以叫"无常",是因为如果价格回到初始比例,损失就会消失。但在实际中,价格往往不会回到原点,所以无常损失是 LP 必须考虑的风险。LP 的实际收益 = 手续费收入 - 无常损失,只有手续费收入超过无常损失时,提供流动性才是划算的。

# 飞轮效应: 流动性的正循环

Swap 的经济模型存在一个正反馈循环:

1. **手续费吸引 LP**: 手续费收入激励更多人提供流动性
2. **流动性改善价格**: 池子资金越多,单笔交易对价格的影响越小,用户能获得更好的兑换价格
3. **好价格吸引交易**: 更好的价格带来更多交易量
4. **更多交易产生更多手续费**: 交易量增大,手续费收入增加
5. 回到第 1 步,循环继续

这就是 DeFi Swap 能够在没有中心化运营方的情况下,靠经济激励自行运转的根本原因。

## 本章小结

本章介绍了 Swap 的经济模型：

- **流动性提供者 (LP)** 向资金池存入代币，是 Swap 运转的基础
- **手续费** 是 LP 收益的来源，Uniswap V2 每笔收取 0.3%
- **LP Token** 代表你在池子中的份额，随着手续费累积而增值
- **无常损失** 是 LP 的主要风险，LP 实际收益 = 手续费收入 - 无常损失
- **飞轮效应** 使 Swap 形成正循环：手续费 → LP → 流动性 → 好价格 → 更多交易
